One visit, four desks

Follow one appointment from the front desk to the invoice.

  1. Reception books the slot

    Only free slots are offered. A doctor or a patient can never be booked twice at the same time.

  2. The doctor consults

    The day reads by the clock. Consult opens the record: symptoms, diagnosis, prescription. Saving completes the visit.

  3. Accounts bills it

    Finished consultations wait for a bill with the fee filled in. Record the payment, then print the invoice.

  4. The patient sees their file

    Their own appointments, records and bills, and nobody else’s.

Questions

Does it need a database server?
No. It uses Node’s built-in SQLite, so Node 22.5 or newer is enough.
Where does the data come from?
The first start generates five months of demo records, dated around today.
How are passwords kept?
Hashed with scrypt, behind HttpOnly session cookies.

Run it on your machine

Then open localhost:3000. On Windows, double-click start.bat.

Open the demo 
$ git clone https://github.com/Krsh-hub/hospital-management-system.git
$ cd hospital-management-system/app
$ npm install
$ npm start
